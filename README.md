# 🛍️ Est Marketplace

A web-based marketplace platform that connects local producers with consumers, promoting local trade and sustainable commerce.

## 🚀 Features

- 🧑‍🌾 Seller registration & product management
- 🛒 Buyer account & cart system
- 🔍 Product search and filtering
- 📦 Order placement and tracking

## 🛠️ Tech Stack

- **Frontend**: React.js
- **Backend**: Laravel
- **Database**: MySQL
- **Authentication**: Laravel Sanctum
